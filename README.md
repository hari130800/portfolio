# Hariharan S — Motion Portfolio

A responsive React + Vite portfolio with animated ambient glows, orbital rings, floating technology chips, a code-card hero, scroll reveals, hover effects, and mobile navigation.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Extract this project folder and open it in VS Code.
3. Open Terminal in the project folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address Vite prints (usually `http://localhost:5173`).

## Before publishing — personalize these items

- Replace `your.email@example.com` in `src/main.jsx` with your real professional email.
- Replace the GitHub and LinkedIn profile URLs with your own profile URLs.
- Add real repository/demo links to the projects. Project descriptions are based on the project concepts shared so far; update them to accurately reflect what you have completed.
- Add a downloadable resume link if you want one.

## Build for deployment

```bash
npm run build
```

The production-ready site is generated in `dist/`. You can deploy that folder to a static host such as Vercel, Netlify, or Cloudflare Pages.
